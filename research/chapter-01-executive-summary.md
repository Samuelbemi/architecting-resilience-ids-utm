Windows-based enterprise environments remain a significant component of modern organisational infrastructure and are exposed to a range of network-based threats, including reconnaissance, unauthorised access attempts, malicious traffic, and exploitation of exposed services. Relying on a single security control is insufficient to address these threats because attacks may originate from different network locations and may bypass individual defensive mechanisms. This research, “Architecting Resilience: A Practical Evaluation of Intrusion Detection Systems (IDS) and Unified Threat Management (UTM) in Windows Enterprise Defence-in-Depth,” investigates the practical application and effectiveness of layered network security controls for protecting Windows enterprise environments.
The study adopts an experimental and practical approach using a virtualised laboratory comprising a Windows 11 Pro endpoint as the case-study system, Kali Linux as a controlled attacker and security-testing platform, Snort as the Intrusion Detection System, and pfSense as the Unified Threat Management platform. Controlled network security scenarios are conducted to generate and observe representative attack and reconnaissance traffic, including connectivity testing, port scanning, service enumeration, and other controlled network activities. Network traffic, IDS alerts, firewall decisions, and system responses are collected and analysed to evaluate the detection, prevention, visibility, and monitoring capabilities of the security controls.
Particular attention is given to the interaction between IDS and UTM technologies within a defence-in-depth architecture. The research recognises that network security controls operate according to traffic paths and network architecture; therefore, traffic that remains within the same local network may not traverse a gateway-based UTM device. This provides an opportunity to evaluate the complementary roles of network intrusion detection and gateway security rather than assuming that a single security control provides complete protection.
The findings are intended to provide practical, evidence-based guidance for organisations seeking to strengthen Windows enterprise security through layered network defence. The study demonstrates how combining network monitoring, intrusion detection, firewall enforcement, and controlled security testing can improve security visibility and resilience while also identifying the limitations and appropriate deployment considerations of each technology. The research ultimately contributes a practical framework for evaluating IDS and UTM capabilities within a Windows enterprise defence-in-depth strategy.
