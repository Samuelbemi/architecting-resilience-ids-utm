# Research

This directory contains the main research documentation for:

**Architecting Resilience: A Practical Evaluation of Intrusion Detection Systems (IDS) and Unified Threat Management (UTM) in Windows Enterprise Defence-in-Depth**

The research is structured around the following major sections:

1. Executive Summary
2. The Windows Enterprise Security Challenge
3. Defence in Depth for Windows Enterprise Environments
4. Practical Implementation and Experimental Evaluation
5. Results and Discussion
6. Practical Recommendations for Organisations
7. Limitations and Considerations
8. Conclusion
9. References

The research documentation will be developed alongside the practical laboratory implementation, experimental scenarios, evidence collection, and results analysis.
