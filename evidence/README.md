# Experimental Evidence

This directory contains the evidence collected during the controlled experimental scenarios conducted as part of the research.

The evidence is intended to support the observations, analysis, and conclusions presented in the research.

## Evidence Categories

### Screenshots

Screenshots documenting relevant laboratory configurations, test execution, security alerts, firewall policies, and observed results.

### Kali Linux

Evidence generated from the controlled test/attacker machine, including relevant command output and network-testing results.

### Snort

Evidence generated by the Snort Intrusion Detection System, including alerts, packet-processing information, and relevant detection output.

### pfSense

Evidence generated by the pfSense Unified Threat Management platform, including firewall decisions, traffic logs, filtering results, and relevant security events.

### Windows

Evidence collected from the Windows case-study endpoint, including firewall configuration, network responses, and relevant security observations.

## Evidence Management

Evidence will be organised according to the experimental scenarios and will be linked to the corresponding methodology and results.

Sensitive information such as passwords, recovery keys, private credentials, authentication tokens, private keys, or other confidential information will not be published in this repository.

Only evidence necessary to demonstrate and support the research findings will be included.
