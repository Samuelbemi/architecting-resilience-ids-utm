# Results and Analysis

This directory contains the results and analytical outputs generated from the controlled experimental scenarios.

The results will be used to evaluate the practical effectiveness of the implemented security controls and support the conclusions of the research.

## Results Structure

### Raw Data

Contains original experimental observations and outputs collected during testing.

### Analysis

Contains the interpretation and analysis of experimental findings.

### Results Tables

Contains structured tables used to compare:

* Network visibility
* Intrusion detection
* Traffic filtering
* Traffic blocking
* Windows endpoint protection
* Snort IDS performance
* pfSense UTM behaviour
* Combined defence-in-depth effectiveness

## Comparative Evaluation

The results will be used to compare the practical security contributions of:

1. Windows endpoint security controls
2. Snort IDS
3. pfSense UTM
4. Combined IDS and UTM controls

The analysis will consider both the capabilities and limitations of each security layer.

Final conclusions will be based on evidence collected from the controlled experimental environment rather than theoretical assumptions alone.
