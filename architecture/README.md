# Architecture

This directory contains the network and security architecture documentation for the research project:

**Architecting Resilience: A Practical Evaluation of Intrusion Detection Systems (IDS) and Unified Threat Management (UTM) in Windows Enterprise Defence-in-Depth**

The architecture documentation will describe:

* The overall experimental network topology
* IP addressing and network configuration
* Windows enterprise case-study environment
* Kali Linux test/attacker environment
* Snort IDS placement and monitoring
* pfSense UTM placement and security functions
* Network traffic paths
* Defence-in-depth security layers

Diagrams and supporting architecture documentation will be added as the laboratory environment is finalised.
